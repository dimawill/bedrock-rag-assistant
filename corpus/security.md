# Security pillar — study notes

The Security pillar of the AWS Well-Architected Framework focuses on protecting data, systems, and assets. Apply least-privilege IAM so each workload identity has only the actions and resources it needs. Encrypt data in transit with TLS and data at rest with an appropriate server-side encryption option. Log access and security-relevant activity to make investigation possible. In a proof of concept, a private bucket and blocked public access are starting controls, not a complete security review.
